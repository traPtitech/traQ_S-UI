# Contributing to traQ_S-UI

Thank you for helping improve traQ_S-UI.

traQ is an open-source project created by a student club and also has an educational purpose. We welcome ideas and implementations for new features and improvements. To keep contribution opportunities available to learners, please keep the following in mind.

## Choosing an issue

Before starting work, check the issue, its comments, and any linked pull requests.

- Do not take an issue that is already assigned to someone else. If ownership is unclear, ask in the issue before starting work.

For issues labelled `easy` or `good first issue`, please follow these rules:

- Do not delegate an issue entirely to AI agents; contributors should understand and be able to explain the submitted work.
- Do not claim or complete a large number of these issues. Leave accessible starting points for other new contributors and consider issues of different difficulty levels.

## Developing and submitting a change

Follow the [development guide](./docs/development.md) for setup, commands, and checks. Run the checks relevant to your change, then open a pull request using the provided template. Explain why the change is needed and how you verified it.

## Related documentation

Project-specific documentation is available in the [`docs`](./docs/readme.md) directory (currently in Japanese). For changes that span the frontend and backend, see the [traQ Backend Development Guide](https://github.com/traPtitech/traQ/blob/master/docs/development.md).
