# Contributing to traQ-S UI

Thank you for helping improve traQ-S UI.

## Choosing an issue

Before starting work, check the issue, its comments, and any linked pull requests.

- Do not take an issue that is already assigned to someone else. If ownership is unclear, ask in the issue before starting work.
- Issues labelled `easy` or `good first issue` are learning opportunities. Please do not delegate one of these issues entirely to AI agents; contributors should understand and be able to explain the submitted work.
- Please do not claim or complete a large number of only `easy` or `good first issue` issues. Leave accessible starting points for other new contributors and consider issues of different difficulty levels.

## Developing and submitting a change

Follow the [development guide](./docs/development.md) for setup, commands, and checks. Run the checks relevant to your change, then open a pull request using the provided template. Explain why the change is needed and how you verified it.
